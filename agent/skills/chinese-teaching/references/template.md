# 初中语文完整教案模板（严格框架 + 飞书可读版）

> 成品必须服从正式教案大框架；四层模型是生成前的设计内核，不替代栏目。生成前先完成：基础进入层 → 文本结构地图层 → A→Z / 课堂生成层 → 正式成品层。也就是先处理作者背景、字词朗读、文体/单元位置和学生起点；再画清文本怎样组织材料、情感、结构转折和写法功能；再推出课堂终态、认知落差、主问题、活动链、证据链、追问链与评价闭环；最后装入基本信息、教材分析、学情分析、目标、重难点、方法准备、教学过程、板书、作业、反思/评价。

### 4. 课堂推进线


A：学生已有理解/文本表层现象
→ 认知落差一
→ 文本证据一 + 活动一 + 追问一
→ 结构分析：文章怎样组织材料、推动情感/观点/人物理解
→ 认知落差二
→ 文本证据二 + 活动二 + 追问二
→ 情感/主旨/写法提升
→ Z：可检测的理解或迁移产出

### 5. 结构地图（前置）

用 3–6 个箭头写清文章自身的组织逻辑，不是课堂流程复述。例如：开篇现象 → 核心转折 → 回忆/对照 → 主旨生成 → 结尾收束。结构地图必须先于具体教学过程生成。

## 十一、教学反思 / 评价设计

**课堂评价**：用出口任务、课堂表达、任务单完成情况等验证学生是否到达 Z。

**课后反思**：记录本课主问题、问题链、学生活动和作业反馈中需要调整的地方。

---

## 十二、可用性检查

- 教师能不能进场：基础进入层是否足够且不游离？
- 文本有没有站起来：结构地图是否清楚且前置？
- 学生能不能走到终点：活动链、证据链、追问链是否递进？
- 教师能不能直接用：课堂语言、板书、作业、评价是否可执行？
