# 教案 Review / 二稿重写协议（渐进式披露）

本文件在生成、修改或评审完整初中语文教案时读取。它不是额外栏目模板，而是交付前的质量控制程序：先发现主要矛盾，再重写薄弱段落，最后才交付飞书文档。

## 1. Review 的目的

用户真正要的不是“看起来完整的教学设计”，而是一个能替教师完成教研判断、并把学生从 A 带到 Z 的课堂系统。

因此 review 不做形式主义打分，不在文末贴“自评通过”。它要回答：

- 这份教案有没有从文本事实和学生起点推到课堂终态？
- 基础进入层是否真的帮助学生进入文本和主问题？
- 文本结构地图是否让文本站起来，而不是段意复述？
- 主问题和问题链是否形成认知因果链？
- 教师语言是否能把浅层回答推深、说清、说美？
- 成品是否符合正式教案大框架且可扫读、可直接上课？

## 2. 何时必须执行

必须执行 review：

1. 生成完整教案、公开课教学设计、长讲义或任务单；
2. 用户提供 PPT / DOCX / 样稿，要求转成或优化为教案；
3. 用户要求“更像优秀教案”“更深”“能直接上课”“不要空壳”；
4. 初稿超过 800 字且准备交付飞书文档；
5. 对既有教案做质量评审、磨课建议或二稿优化。

短问短答、局部改一句课堂语言、只要一个主问题时，可以只用轻量检查。

## 3. Review 的基本执行顺序


初稿/待评审稿
→ 识别主要矛盾
→ 六维质量检查
→ 对薄弱维度定位到具体段落
→ 重写薄弱段落
→ 再检查成品形态和可读性
→ 创建/更新飞书文档并回读验证

关键原则：**不要机械增加栏目来修问题**。如果问题是“基础进入层不能开文本”，就重写基础进入层；如果问题是“问题链断裂”，就重写问题间的因果推进；如果问题是“教师语言干瘪”，就重写教师引入、追问、提升和收束。

## 4. 先抓主要矛盾

review 的第一步不是给每个栏目扣分，而是判断这份教案当前最阻碍它从 75 分到 85 分的主要矛盾。

常见主要矛盾：

| 症状 | 主要矛盾 | 修法 |
|---|---|---|
| 栏目完整但像模板 | 没有 A→Z 设计内核 | 重做文本事实/学生起点/课堂终态/主问题 |
| 字词、作者、背景很多 | 基础知识没有功能化 | 改为入口现象、字词功能、背景功能、文体期待、主问题过渡 |
| 教学过程像赏析题集合 | 缺文本结构地图 | 增补材料组织、情感运动、关键转折、写法功能 |
| 主问题存在但课堂不饱满 | 问题链没有认知压力 | 写出浅层答案为什么不够、教师如何追问提升 |
| 每环节都有活动但很散 | 活动没有服务同一终态 | 删除装饰活动，保留证据链/活动链/追问链一体推进 |
| 教师语言全是说明 | 课堂不可说、不可生成 | 写可说出口的引入、接话、追问、提升、收束 |
| 结尾突然升华 | 主旨不是从文本生成 | 回到证据、结构对照、情感变化推主旨 |
| 文档密密麻麻 | 可读性失败 | 改为短段、表格、问题块、任务导航、板书图式 |

只允许围绕 1–2 个主要矛盾做重点重写。不要把同质问题拆成很多空洞字段。

## 5. 六维 Review 标准

### 5.1 A→Z 设计内核

检查问题：

- A 是否清楚：文本事实、课程目标、学生起点是否具体？
- Z 是否可检测：学生下课后能说清、做出、迁移什么？
- 认知落差是否真实：学生凭直觉会停在哪里？
- 主问题是否由落差推出，而不是为了好看临时造？
- 证据链、活动链、追问链是否共同服务 Z？

不合格信号：

- 教学目标是套话；
- 主问题和目标没有因果关系；
- 活动很多，但删掉某个活动后不影响理解路径；
- 评价只写“完成练习”，无法证明学生到达 Z。

重写动作：


重写一段“设计内核”：
文本最关键的表达机制/情感运动是什么；
学生最可能停在哪个浅层理解；
本课要把学生带到哪个可检测终态；
因此主问题为什么必须这样问。

### 5.2 基础进入层

检查问题：

- 字词是否说明了它们如何打开文本，而不是只列读音释义？
- 背景是否解释主问题需要的处境，而不是作者生平堆砌？
- 文体知识是否给出阅读期待？
- 导入是否低门槛进入文本现象，而不是空泛情境？
- 基础进入结束后，是否自然引出主问题？

不合格信号：

- “生字词：……作者简介：……写作背景：……”孤立罗列；
- 导入只问生活经验，和课文核心机制无关；
- 背景很多，但学生仍不知道为什么要回到文本。

重写动作：


入口现象：从标题、首尾动作、核心意象、语气反差或人物选择进入。
字词功能：每个重点字词都说明它服务景物状态、情感变化、人物精神、结构转折或主问题。
背景功能：只补解释文本触发点所必需的背景。
文体期待：说明这种文体应该怎样读。
主问题过渡：让学生知道下一步必须回到文本取证。

### 5.3 文本结构地图

检查问题：

- 是否说明文章怎样组织材料、情感、意象、人物或观点？
- 是否抓住关键转折，而不是只复述段意？
- 结构分析是否服务课堂问题链？
- 学生能否通过结构地图理解“为什么这样写”？

不合格信号：

- “第一部分写……第二部分写……”只有内容分段；
- 只讲修辞效果，不讲结构运动；
- 情感/主旨像最后贴上去的结论。

重写动作：

按文体选择结构抓手：

- 现代散文：眼前景物 → 回忆/联想 → 情感转折 → 哲理/行动收束；
- 文言文短篇：核心判断 → 铺陈证明 → 语气/句式收束；
- 古诗词：意象组合 → 时空转换 → 情感层进 → 末句收束；
- 小说：冲突 → 选择 → 细节照应 → 人物复杂性；
- 议论文：观点 → 论据 → 递进/反驳 → 收束；
- 说明文：对象分层 → 顺序 → 方法 → 清晰化。

### 5.4 主问题与问题链

检查问题：

- 主问题能否统摄全课？
- 每个问题块是否解决主问题的一部分？
- 问题之间是否自然生长，而不是并列堆叠？
- 每个关键问题是否写出学生浅层答案和教师追问？
- 追问是否迫使学生回到文本证据？

不合格信号：

- 问题多但没有主问题；
- 问题之间靠“接下来我们……”硬转；
- 只有“明确：……”答案，没有学生生成和追问提升；
- 活动热闹但不改变学生理解。

重写动作：

每个关键问题块至少包含：


本块目标：解决哪一个认知台阶。
教师引入：上一环节解决了什么，但还不足以抵达 Z，所以为什么问这个。
核心问题：一个主问，最多两个追问。



学生浅层答案：学生最可能怎么答。
为什么不够：浅层答案缺了哪一层文本/结构/情感理解。
文本证据：必须回到哪些词句、结构或语气。
追问提升：教师如何把答案推深。
小结过渡：本块如何进入下一块。

注意：不要把“承接上一环节 / 认知空白 / 转场语言”拆成三个重复栏。它们本质上是一件事：**下一个问题必须从上一个课堂发现里自然长出来**。

### 5.5 教师语言

检查问题：

- 教师语言是否可直接说出口？
- 是否能把学生浅层回答接住并推深？
- 是否有文学性，但又不脱离文本？
- 收束语是否概括本课真正生成的理解，而不是空喊价值？

不合格信号：

- 全是“引导学生体会……”；
- 没有具体接话和追问；
- 名言/高级句子贴上去，和文本证据无关；
- 课堂小结像作文素材。

重写动作：

补三类语言：

1. 主导性过渡语：从上一发现进入下一问题；
2. 追问提升语：把浅层答案推向语言、结构、审美、思想；
3. 文学性收束语：用文本中的关键词、意象、语气或结构收束。

语言可以有文采，但必须从文本证据中生长出来。

### 5.6 成品形态与可读性

检查问题：

- 是否符合正式教案栏目？
- A→Z 是否作为设计内核，而不是替代教案栏目？
- 飞书文档是否短段、可扫读、有层级？
- 板书是否是思维脚手架？
- 作业是否复现本课学习路径？
- 删除 PPT 后是否仍能独立上课？

不合格信号：

- A→Z 表格很完整，但不像正式教案；
- 正式栏目齐全，但内容空壳；
- 文档大段密集，教师难以扫读；
- 板书只是标题堆叠；
- 作业和课堂主线无关。

重写动作：

- 用正式教案大框架承载内容；
- 在“设计总览”中短呈现 A→Z；
- 教学过程改成大环节 → 问题块 → 教师语言/问题/生成；
- 板书画出主问题、结构运动和学生理解路径；
- 作业设计成“复现本课方法 + 迁移表达/赏析”。

## 6. 85 分 Review 输出格式

如果用户要求评审，而不是直接生成最终稿，输出应简洁但具体：


总体判断：约 X 分。
主要矛盾：一句话说明最关键的问题。

1. 最需要重写的部分
- 位置：……
- 问题：……
- 为什么影响课堂：……
- 重写方向：……

2. 可以保留的亮点
- ……

3. 二稿重写建议
- 基础进入层：……
- 结构地图层：……
- 问题链：……
- 教师语言：……
- 评价/作业：……

不要只给抽象评价；每条建议都要能落到具体段落和重写动作。

## 7. 生成教案时的内部二稿协议

如果任务是生成完整教案，而不是评审别人稿件，review 不应完整暴露给用户。内部执行即可：

1. 先生成初稿；
2. 按六维标准找 1–2 个主要薄弱点；
3. 直接重写薄弱段落；
4. 最终文档只保留必要的“评价设计/教学反思”，不要把内部自检流水账塞进成品；
5. 再创建/更新飞书文档并回读验证。

## 8. 轻量版交付前自问

完整教案交付前，至少问：

- 基础进入层能否把字词/背景/文体变成进入文本的支架？
- 文本结构地图是否先于课堂活动？
- 主问题是否从主要矛盾里长出来？
- 问题链是否有“学生浅层答案 → 为什么不够 → 文本证据 → 教师追问 → 新理解”？
- 教师语言是否可说、可接、可提升、可收束？
- 成品是否正式、可扫读、脱离 PPT 也能上课？

任一项为否，先重写，不交付。
