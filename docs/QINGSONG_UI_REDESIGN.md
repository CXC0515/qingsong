# 青松教师 UI 方案与原型历史

版本：v0.11 · 2026-10-23
状态：原型阶段历史存档；用户已批准正式接入，候选实现待使用验收，未发布。
本次概要：最终 E 材质与统一浅阴影已转入正式组件，课次续接/项目改名已接入本地真实服务。

正式视觉规范以根目录 [DESIGN.md](../DESIGN.md) 为准；真实业务与迁移以 [课堂课次与改名](./CLASSROOM_LESSON_PROJECTS.md) 为准。以下章节保留 v0.1–v0.10 原型阶段的方案、参数演变和当时的边界，包含“未批准生产接入”等历史措辞，均不覆盖上述当前规范。

## 1. 原始需求和边界

教师需要知道当前班级、选择记录项目、找到学生、快速记录并纠正。主要矛盾是操作和信息层级不稳定：班名被裁切、选择器分散、说明不必要地折叠、项目管理不完整。材质服务于层级和触感，不能增加点名延迟。

最终目标覆盖整个青松教师 UI，而非只给课堂任务换色。当前批准范围为方案文档与独立交互原型（含用户反馈修正），生产代码、后台项目改名、真实数据和部署尚未实施。本原型不冒充生产功能或可持久化的数据闭环。

## 2. 已确认事实与假设

- 当前统一入口位于 `src/app/AppLayout.tsx`，全局样式位于 `src/index.css`；已有玻璃主要为底色、blur、边框和阴影。
- 班级选择分散在壳层、课堂任务、诊断、可视化和课表。触发器与移动弹层不完全统一；课堂任务局部 classId 与全局入口还需统一控制源。
- 项目已有稳定 key；目前缺少改名接口，历史表现摘要存在从记录快照取名称的路径。改名需要贯通当前目录名称与历史审计，不能只换按钮文字。
- 用户认可 Movies 的克制通透风格，并明确要求采用自己的 liquid-glass skill。
- 手机默认三列是候选产品决策；本原型用 40 个虚构姓名，含四字姓名。真实教师、字号放大与真机误触率仍待验证。

## 3. 统一视觉语言

- 青松色主调、浅暖底色，背景只提供低对比色温，不做持续运动。
- 导航/工具栏/选择器：局部边缘折射、细反光、轻投影；文字独立于滤镜。
- 菜单/弹层：提高底色不透明度，保证长文字、焦点和选项可读。
- 学生名单/表格/正文：安静的近实色内容面，不逐卡运行昂贵折射。
- 边缘色散极少量，保持固定左上光源，不自动旋转。
- 语义色表达选中、已交、未交、异常，不以装饰色覆盖结果含义。

## 4. 材质实施方案

直接复制 `/Users/cxc/.codex/skills/liquid-glass/assets/runtime/` 需要的七个运行文件（含按压反馈），原样保留其算法。来源与接口以用户 skill 为准；无新增 npm 依赖。

当前配置以用户 skill 的 defaults/presets 为唯一来源，不设置项目私有几何和光学数值：

- 公共：lightAngle225、reflection0.8，静止光源；浅色界面选择 light theme。
- button：radius26、edgeWidth11、displacement6、blur1.25、rimWidth0.85；实际圆角由 runtime 按短边限制。
- toolbar：radius28、edgeWidth12、displacement7、blur1.25、rimWidth0.85。
- lens：radius48、edgeWidth23、displacement16、blur0、rimWidth1.15。
- 普通材质 dispersion0；分段选中片保留 mountSegmented 内置 dispersion1.35、radius999、edgeWidth7、displacement3、blur0.7。类别控件与班级选择器共用 toolbar 玻璃宿主，内部连续选中片使用 trackRim:false 避免重复深色底座；保留 liftPx2，节奏155ms、380ms不覆盖。
- 按压反馈不再私自传 travelPx，使用 skill 原值。保留调节入口供用户自行对比，恢复基准会重建实例避免残留覆盖。
- 不改 runtime 的阴影与高光算法；移除整体玻璃工具栏包裹，避免它和各个动作按钮形成嵌套阴影。弹窗清晰阅读底面只在中心区域，距边缘7px，不覆盖边缘反光。

此前v0.1/v0.2的0.35色散、自设圆角/位移/模糊和主次底色覆盖均已撤回；以下历史记录只供追溯。

原型右上/手机底部「材质」支持即时调节反光、色散、位移、模糊，另有原生折射开关。细线对照使用真实 DOM 网格，未复制页面快照；清透样片 blur0，业务控件允许轻模糊。关闭原生路径只代表基础反光/模糊降级，不代表等价折射。

原生 SVG 背景滤镜的实际折射必须按浏览器验收，不能把语法支持或属性存在当作视觉通过。首选现有 skill；暂不另引第三方 React 库，避免同类材质双实现。

## 5. 交互决策

### 班级

公共 ClassPicker 单一控制源：触发器固定箭头槽，文字可换行。手机单独完整一行；移动选择器底部弹层，长名称不裁切。原型工作台与课堂任务共享当前班级，记录按班级/项目/日期/轮次隔离。历史中的“所有班级”属于筛选语义，不强制等同当前记录班级。

### 课堂任务

内容区最上方左侧放学业/表现连续移动的分段选中片，删除重复大标题和说明；项目紧随其后，新建紧跟项目。选中项目旁直露「改名」。统计与项目标题同排，保存提示将接在统计附近，不新增空白占位。

手机名单默认三列，窄于340px回退两列；姓名和学号分行，卡片至少82px，独立未交目标44×44px。桌面自动填充列数，卡片约78px。点击姓名立刻改变示例状态，撤销恢复上一状态；表现重复点击加一。不展示“保存中”阻塞层。

说明一直展开：桌面位于工具栏右侧，手机占工具栏下一行。表现说明用于接下来每一笔，历史详情可查；学业检查内容的生产语义应绑定整轮，开始记录后编辑需明确新旧范围。本原型仅演示输入、记录快照，不代表后台整轮内容已接入。

### 项目改名

所有项目，包括默认项目，都应支持改名。目录名称跨本教师班级更新；稳定 key 不变，不迁移/覆盖原事件。历史列表与画像聚合优先显示当前名称，事件详情可保留记录时名称；具体轮次内容/任务标题不随目录改名覆盖。分类和结果模式不能借改名悄悄变更。

### 工作台与 Agent

页头只保留工作台与紧凑日期；不展示大问候语/英文日期/装饰性说明。今日课表、日程待办、教学任务三个区域独立，常用工作与未来助手区域保留。桌面固定剩余视口、长列表在各模块内部滚动；手机按正常文档流滚动。会话区域仅显示“预留，暂未接入”，不冒充可用 Agent。

教师今日课表是教师当天各班课程集合，不受某个当前班级过滤而漏课。进入某一节课才带入其班级、日期及课次。日程完成与课堂记录互不联动：勾选日程不会结束课程或归档检查。日程内每条事项的展示形式按用户最新要求暂定，当前样式只作占位，不能视为用户已认可。

## 9. 课次、项目与轮次逻辑（v0.4，用户已确认设计）

### 概念与不变量

- 课次：教师在某个具体日期上的一节课程，是记录上下文。每周循环课表条目不等于具体课次；下周同一节是另一个课次。
- 项目：作业收交、课文背诵、课堂发言等稳定记录类型，复用现有 projectKey，不靠名称匹配。改名不改变课次/记录归属。
- 检查轮次：同班级/项目/日期中的一次检查。课次与项目绑定其已建立的检查，不能把“第几节课”当成轮次号。不同项目有各自的轮次。
- 原始记录继续追加。重测/撤销不覆盖旧事件，未记录不等于未交；任何一次跳转都不能清空旧名单结果。

### 教师流程

1. 工作台展示完整今日课表，每节有“去记录”。进入时带入该课班级、日期和稳定课次标识；选好项目后直接点学生。
2. 仅打开或反复进入课程，不创建空检查。首次实际记录时建立该课次/项目的检查绑定。
3. 同课次、同项目返回、刷新或重进，续接原检查。保存待核对时也不能误开新轮，先恢复原操作。
4. 另一课次使用独立检查；同一天同一班的第1节与第3节不能因项目同名而合并。
5. 在同一课内主动“新一轮”建立新的检查，不覆盖前一轮。再次进该课默认续接最近一轮，旧轮需要有回看路径。
6. 同一班级/项目/日期的编号跨课次保持唯一、递增；返回较早课程后再开新轮也须用当前最大号之后的编号，不能碰撞其他课已用的轮次。显式开始空新轮可能预留编号，不以连续无缺号为业务保证。
7. 常用工作中的“课堂记录”是自由记录入口，没有课次时使用单独绑定，不能误续接某节课的检查。手动更换日期或班级会退出课次上下文，并明显展示当前目标。
8. 待跟进入口必须打开其既有 taskId/classId，不触发自动新轮；不能靠项目名重建旧任务。

### 稳定标识与生产实现边界

计划中的课次唯一标识需要包含教师工作区、具体上课日期和稳定课表条目/课次ID，不依赖可能改动的课名、显示时间字符串或项目名。保存时应保留课程/班级/时间快照用于解释历史。改课、调课或班级变化不能静默把历史绑定迁到另一节课；先核对目标并给教师明确反馈。

现有后端 `classroom_quick_rounds` 只按 class_id/project_key/check_date/round 绑定 task_id，尚无课次关联。生产阶段需要增添稳定课次→项目→检查绑定，在事务内分配唯一轮次；同课次的重复请求/多个标签页必须幂等续接，不依赖客户端加一。响应丢失沿用 operationId 核对，不重复保存；保持工作区隔离、固定名册快照与版本校验。

这部分目前是已确认设计，不是已上线接口；原型用本标签页的本地样例映射演示，不能证明服务端并发、跨设备、调课迁移或真实保存恢复已经完成。

### 当前原型与验证范围

- 固定示例日期2026-10-23，3个虚构课次；第1/3节同班，便于验证跨课次不串记录，第5节另一个班。
