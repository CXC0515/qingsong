# 教案会话入口归属补修

版本 v1.0；2026-11-06；状态：实现及本机检查完成，Linux验证与发布中。

目标：一份教案多会话，每条会话仅属于一份教案。事实：后端禁止串绑，但原生侧栏新建绕过绑定，切换未同步教案页面。

最短路径：业务接口核对原生选择的归属；仅允许当前备课工作区内、尚未开始对话的空会话首次绑定，已有绑定永不改写，非空未绑定会话不自动认领。订阅原生正式store的mainView引用计数，已有其他教案会话请求打开原教案。页面接收选择走草稿离开保护，往返恢复正确会话。备课空间未关联会话不得提交模型回合。无SDK修改或DOM拦截。

范围：agent/official-ui/{client.js,navigation.js,shell.css}，server/services/assistant/{preparationAssistant.ts,officialAssistant.ts}，src/App.tsx，LessonPlanWorkspace.tsx及对应测试/专项文档/交接。

取舍：复用原生目录及绑定表；放弃改SDK、认领旧非空会话、从页面强行重绑。风险为异步过期回执、草稿拒绝切换后的错位、重复认领。验证多会话、跨教案往返、刷新、目录延迟/取消、账号隔离和旧非空会话拒绝；实际壳层桌面/窄屏，Linux同权限构建/测试，生产健康及数据核对。真实模型、正式账号、真机验收单列。无数据迁移或删除。


## 已实现与证据

- 业务层首次认领仅接受原生目录中同一备课路径的空会话；读取原生标准参数使用 _request，路径取 realpath。已绑定会话返回原教案归属，不重新绑定；备课路径未绑定会话提交回合返回409，消息未提交。新建请求禁止复用已经绑定的空会话。
- 助手通过正式 sessions.list 的 mainView 观察选中会话，核对时使用modal dialog阻止键盘/鼠标继续提交；消息校验origin/source/connection/request。过期回执不能覆盖后选会话；失败可重试、返回原会话。新绑定完成后刷新关联标签。
- 页面同步教案和会话选择；草稿保存未完成时拒绝切换，保留正文及原会话；用户显式重试后再切换。不改变主Agent、Skill、模型、候选应用规则和材料权限。
- 本机类型及构建通过；绑定/导航/原生运行时/材料回归33项通过，另新增原生选择过期回执测试通过。完整HTTP/DSH四项已通过，新增原生空会话首次绑定、未绑定提交409、跨教案保留归属、新建不能复用已绑定空会话断言通过。最终Linux重跑结果待填。
- Playwright真实应用壳层合成账号：原生侧栏新建后A有两条绑定；A/B原生切换同步教案；刷新回到A后恢复A的未发送草稿；模拟正文保存延迟时阻止切到B，正文保留。390×568页面宽390、iframe宽374且无横向溢出，助手输入区可见；截图 /tmp/qs-navigation-qa-2026-11-06。是真实壳层的本机合成数据，并非正式账号、真实模型或手机真机验收。
- 联调曾发现目录接口参数名及macOS路径规范化问题，已修并通过真实DSH接口复验。早期浏览器验收遇开发服务器文件监视触发整页刷新，最终关闭HMR后复验；一次路由延迟模拟清理报Route already handled，已清理并另行完成窄屏检查，不当作产品故障或全套无错误。
