# 第一批：用户个人规则、长期记忆与常用查询

版本1.1 · 2026-10-27 · 状态：已部署，代码审查与自动检查通过；网页验收由用户负责。

## 本次概要与授权

目标：跨会话使用教师明确保存的个人约定，提供查看/编辑/停用/删除入口，并补齐座位、提醒、课堂任务逐人明细/历史及画像依据查询。用户纠正为一个人一份记忆库，并明确要求快速实施、由用户自行网页验收。沿用第一批方案中的文档、实现、检查、推送PR、合并、备份部署流程。无浏览器操作、真实模型调用或第二/三批资料RAG与业务写入。

## 事实与取舍

- 最新基线 origin/main@c09cd18；独立 codex/assistant-personal-context，复用本聊天独立 worktree，保留旧浏览器检查产物。
- 当前用户身份由服务端 WorkspaceContext 提供。个人库按 userId 的SHA256定位 `system/assistant-users/<hash>/assistant-context.sqlite`，不按聊天或业务工作区创建副本。
- 现有产品快照对system/workspaces下所有.sqlite使用在线备份；新增用户库复用该机制，补充恢复测试，不更改既有教学表。
- 规则/记忆结构化存储，附版本、原始来源、有效期和删除标记；当前业务事实仍经工作区授权查询。
- 不安装外部memory服务，不引入向量库，不启用任意SQL/文件/Shell或教学业务写入。

## 接口与控制

新增个人上下文HTTP接口及助手“规则与记忆”管理入口。只有真实登录用户可管理自己的条目；版本冲突拒绝覆盖，操作编号保证重试不重复。模型只能提出候选，不自行签发确认。明确的原文记忆命令仅在服务端记录的人类消息及受信插件原文均匹配时可直接生效；其他归纳必须在管理入口确认。

每轮请求按当前用户加载有效规则和相关记忆，读取最新版本；规则低于公共权限与本次明确要求，记忆作为背景数据。上下文通过请求尾部的独立用户上下文注入，不更改已定稿system prompt。删除/停用/过期条目不再召回；旧对话原文与删除记忆是不同对象，不宣称删除旧历史或备份。

## 实现与接口

- 每用户按SHA256(userId)定位唯一库；首次查询/管理时创建，业务工作区和聊天工作区均不复制。新增数据在system目录下，复用在线产品快照；旧教学数据库不迁移。
- `GET/POST /api/assistant/personal-context`、`PATCH /api/assistant/personal-context/:id`、`GET .../:id/history`：继承青松登录，禁止客户端指定用户/工作区，变更须operationId及expectedVersion；历史版本与来源只对本人可读。
- `qingsong_memory`：list列出有效项（最多20条，标记截断）；propose为候选，教师通过管理入口确认。明确格式“记住：原文”“个人规则：原文”“忘记：原文”只有当插件看到的本轮人类消息与服务器接收的命令哈希一致，且内容完全匹配时直接生效。原命令哈希按实例/会话有界保留；模型不能传confirmed、userId或授权原文。丢失确认信息时保持候选，不猜测批准。
- 管理入口通过官方shell.overlay插槽显示“规则与记忆”，同源父子消息打开青松原生管理弹窗。支持新增、编辑、候选确认、停用、启用、日期到期、删除、版本与聊天来源；离开工作台时关闭管理模态。没有浏览器验收或视觉检查。
- 每条最多600字；有效规则最多10条且合计3000字，有效记忆最多60条，总非删除条目最多150条。每次装载全部有效规则与关键词/近期排序前6条记忆，返回省略数量；超限拒绝生效，不静默截断规则。
- 复用DSH `systemPrompt.context(required=true)`，以可追溯的原生用户上下文快照装载个人规则/记忆，静态persona保持原文。每步重新读取有效版本，内容未变不重复追加快照。删除/停用/到期不再召回；新快照声明旧个人上下文已失效。旧聊天原文、原生上下文快照、历史版本和备份并未物理擦除，管理界面明确展示这一边界。
- 常用查询新增seating、reminders、task、student；classroom/task/student/reminders支持offset/limit，默认50、最多100。课堂/学生日期最多31天；任务参与者与事件分别分页、提供总数；未记录不当作负结果，未参与不当作未完成；提醒按日期区间重叠匹配，并计数未定时间项。
- student仅返回指定班级/日期内已有观察与课堂依据，不输出联系人或家庭信息，不代表完整画像；资料检索和批改查询仍未接通。来源链接补齐受限页面路由与班级/学生编号校验，URL不授予数据权限。
