# 全站公共控件收敛与课堂表现轮次

版本：1.1 · 2026-10-26
状态：用户已批准实施；本地候选，待真实使用验收；未发布。

## 本次概要与授权

用户指出课堂表现缺少新一轮、班级选择过长、工作台和课堂任务的材质不符；随后要求教案、批改、诊断及整个系统举一反三复用组件。用户对全站公共控件、层级/上下文/空状态/弹窗改进，以及课堂表现真实轮次的方案明确回复“同意”，中断后再次要求“继续”。本方案同时覆盖代码和设计文档，保留已定 E 材质、原 Lucide 图标及日程条目展示待定的边界。

目标是让教师稳定识别当前对象、切换工作模式、执行主要操作并看清结果。新轮次不能删除旧事实；视觉统一不能改变评分、点名、权限或证据语义。

## 事实、决策与最短路径

- 原教案/批改/诊断/课表/设置/资料库均自行拼接模式切换；普通操作还混用实心绿、白底和多种阴影。已有 skill 运行时与 `GlassSegments` 可以复用，无需重新写光学算法。
- 旧 `.animate-fade-in` 使用 `opacity`、`transform` 与 `forwards`。实际页面中选中片呈灰色；移除该持久合成状态后，同参数恢复清透选中片。全站页面进入取消这层动画，保留分段内部的连续移动和减少动态偏好。
- 课堂表现原本按日期、课次累计事件，没有持久轮次，单加按钮会在刷新后失效。因此增加轮次元数据，而非清空计数或改写旧记录。
- 不使用全局 CSS 将所有按钮强行玻璃化。普通操作显式接入共享组件，流程阶段、评分键盘、原图证据交互、座位单元、文件树和多选标签保留其专用含义。
- 暂未接通的教案页原“新建”仅弹成功提示。现明确标注功能预览并禁用新建，示例搜索可实际过滤；不把示例宣称为已保存教案，不接入新的生成后端。

## 公共部件与落点

| 部件 | 实现与应用 |
| --- | --- |
| `GlassSurface` | 原 skill 运行时；225°、reflection 1 与 E 底色/阴影不变；屏幕附近才初始化普通玻璃，隐藏或远处按钮避免提前生成光学资源；实例不随点名重建 |
| `GlassButton` | primary / secondary / ghost / danger；容器承担宽度、定位、外间距与响应式显隐，原生按钮承担点击、焦点、禁用与提交语义；常用动作至少44px |
| `GlassSegments` | 同一移动选中片，允许图标；桌面到手机共用模式切换，窄处可横向滚动；状态筛选可使用紧凑密度；没有把批改流程步骤伪装成自由切换 |
| `WorkspaceUI` | 搜索框、工具行、空状态；教案与学生搜索复用同一外框；已有原生字段显式标记 `qs-field-input`，共用尺寸/焦点/背景，选择框箭头固定在右槽 |
| `ClassPicker` | 自然宽度、普通班级约156px、最大180px；班名和箭头分别占位；班级/学生管理、批改新建、课堂、诊断和课表等按各自对象语义使用 |
| `ResponsiveDialog` | 扩充宽弹窗、手机全屏、固定页脚和放弃草稿保护；批改新建、学生详情/编辑/批量操作及课表/日程共用。专用全屏阅卷/座位预览继续保留其布局 |
| `RecordingRoundControls` | 单个轮次选择组件按窗口能力进入桌面上下文行或手机操作行；业务轮次仍由页面持有，切换尺寸不会另建轮次 |

接入范围包括工作台、课堂任务与详情、教案、批改列表/工作流/复核、诊断/画像、班级/学生/标签、课表/日程、材料池/资料编辑/知识图谱、设置及管理入口的常用操作和字段。阅读面、表格、学生卡片不逐个创建玻璃滤镜。教案手机示例按卡片重排，隐藏桌面列标题。

全局班级入口仅在工作台作为“快捷入口班级”出现；诊断、记录、课表、学生筛选和新建任务采用明确的局部班级。未使用全局班级的页面不再显示一个看似能筛选、实际无作用的选择器。实际数据写入对象仍来自原业务状态。

## 表现轮次的真实规则

- 范围：教师工作区 + 班级 + 稳定项目 key + 实际日期 + 课表条目 ID（自由记录为空）。轮次在各范围独立编号。
- 第1轮包含旧无 round 字段的事件，旧事件 JSON 不回填。只读取不会创建元数据。
- “新一轮”显式建立并持久保留空轮次。返回/刷新读取该范围最新轮次，也可以切回旧轮。
- 新建携带 operationId 与 basedOn；相同请求重放返回原轮次，过期窗口返回冲突并重新读取，不静默再加一轮。事件 operationId 的旧第1轮指纹保持兼容。
- 本轮卡片按指定项目/轮次读取，画像继续汇总完整日期范围。次数由服务端完整聚合，最近500笔只是历史展示上限，不作为计数上限。
- 撤销必须匹配原事件的班级、项目、日期、课次和轮次，追加逆向事件。旧课表被移除后，已提交请求仍可核对，原记录仍可撤销。
- 点名排队期间禁止切轮。新轮次请求发送前保留本机原请求；网络结果未知时提供“核对新一轮”，重试同一编号，期间阻止继续点名/切换。普通点名继续复用原有乐观投影、有序队列与恢复机制。
- schema16仅新增 `classroom_behavior_rounds` 和按表现范围读取的索引；不删除或重写已有业务事实。发布时仍需正式在线恢复点和迁移验收。
