## 问题与决策

用户反馈补充入口未关闭弹窗、材质不统一；硬绑定多次修补后仍阻碍备课。已确认入口仅派发事件，原生侧栏选择、发送前检查和备课工具依赖永久绑定。未复现正式账号这次绑定失败的具体原因。

用户批准撤掉硬绑定，优先恢复可用DSH会话链路，再做必要引用接入，避免继续叠加隐式兜底。整体回滚会带走其他已可用修复，不采用。
