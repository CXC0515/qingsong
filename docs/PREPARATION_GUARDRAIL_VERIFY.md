# 备课工具护栏与结果核验

版本：v1.0；2026-11-05；状态：本机检查通过，服务器检查中；尚未部署。

用户批准补充备课操作前检查、执行后核验、未知结果核对及部署。目标：减少错误参数与重复提交，确保回复依据实际任务和候选状态。保留DSH主Agent、现有Skill、教师应用候选的控制边界。

范围：共享动作契约、读取ref、工具恢复、业务状态回读、定向测试。不包含模型图片配置、玻璃组件、联网、资料左置或六点拖动。无schema迁移。

设计：共享定义同时生成工具参数说明及后端验证。后端核对身份、任务轮次、选区、版本与输入指纹，回读保存结果；status只查当前会话/轮次任务。相同begin不再建立第二任务，相同候选以操作编号与请求指纹核对。传输异常先查状态，无法确认时明确未知、不自动重复写入。已有轮次结束钩子清理未完成任务，不承诺拦截所有自然语言输出。

风险：旧任务字段兼容、完成任务的幂等恢复、跨轮隔离。验证：真实失败参数回放、取消/版本/选区/跨轮、重复提交和响应丢失；真实模型与真机未验证。

修改历史：v1.0 记录获批方案及实施边界。

## 实现与检查

- 新增统一动作契约，按动作说明必填字段并在适配器、后端执行相同校验；SDK当前使用扁平参数定义，未伪称已支持条件联合schema。
- begin输出taskId/baseRevision；保留既有id/result兼容。上下文直接给document.ref及所选资料ref，缺parentId报参数错误。
- 复用tools/post-execute的结构化错误回传，备课适配器新增参数指纹、重复错误拦截、停止写入与只读status。内部网络异常核对计入工具预算。
- begin同轮复用任务；propose按operationId与请求指纹核对已保存结果；候选、请求指纹、任务完成及结果核验在同一SQLite事务中，核验不通过回滚。
- 任务更新回读状态；教师应用候选时回读正式正文和候选应用版本。没有新增业务schema或自动应用权限。
- 现有turn/end释放执行轮次、标记未完成任务；本次未增加自然语言最终回复的强制重写或第二评审Agent。教学质量仍由教师验收。
- 本机固定Node24.22.1类型检查及构建通过；49项定向检查、4项完整HTTP/DSH检查通过，无跳过。DSH检查使用本地模拟供应商，包含漏summary后收到字段错误、修正、生成候选及教师应用。真实模型/OCR调用0，未做正式账号网页、真机或教学质量验收。
