## 范围和授权

用户确认三块布局并取消待处理教学任务：左上常用工作2×2、左下课表/提醒独立模块、右下宽扁教学助手、右上留白。新增反馈为座位图记录入口占行、日程四象限/清单与标签大类未复用；两处切换属于此前已批准的全站共享组件范围，本次补齐。不改数据接口、课次语义、日程条目规则或玻璃参数。

实施文件：Workbench、App的调用参数/废弃回调、VirtualClassroom头部、ScheduleReminder视图选择、TagManagement类别选择、product.css工作台布局及设计文档。

## 代码审查

- Workbench已移除summary请求/focus监听、任务和学生风险派生；相关页面和数据仍由原功能维护，未删除业务接口。
- 课表筛选、真实日期、教师各班课程范围、去记录输入保持原逻辑；提醒筛选/排序/条目保持原逻辑。
- 常用入口沿用原导航：课堂任务、grading-flow别名、lesson-plan、onEnterClass；虚拟教室不再重复大卡。
- 明确grid区域和min-height:0分配剩余视口；较矮桌面缩小快捷区到44px操作高度，课表/日程内容在各模块内滚动；手机整页顺排。
- 两个切换的值和回调继续由原页面控制，复用GlassSegments移动片、键盘交互和生命周期，删除旧Tab和标签侧栏选中样式。没有改运行文件或参数。
- 座位图只移动原按钮，保留effectiveClassId、编辑态隐藏、班级选择保存守卫和其他工具。
