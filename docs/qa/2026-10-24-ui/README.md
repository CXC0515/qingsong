## 实际观测

- 1280宽度侧栏210px，类别/班级/日期/轮次/页面切换同排；改名位于项目行右端。正文宽度与视口一致，无整页横向溢出。
- 900宽度侧栏172px，上下文自然分两行，搜索/统计/说明可并排，操作继续换行，无横向溢出。
- 375宽度正文375px，学生网格三列约110px；输入16px；日期背景为透明。搜索/统计同排，四个原有操作同排，说明独立展开。
- 历史页隐藏课次提示，回记录页恢复，避免将课次上下文误解为历史筛选。
- 手机轮次触发器可打开原有选择弹层；搜索“欧阳”找到4个演示姓名，清空恢复完整名单；长班名可完整显示，箭头保持在右侧固定槽位。
- 手机抽屉可打开，保留完整导航与底部账号；Escape关闭并回焦打开按钮。导航列表独立滚动，页面主操作不因侧栏撑高而被挤出。
- 1280×720工作台整页高度720，main可视高度/scrollHeight均640，助手预留区域和各业务模块仍在；长列表仍使用模块内滚动。
- 类型检查与生产构建通过。全局CSS导入顺序警告已修正；既有大包提示保留。本轮没有重跑未改动的后端专项，也没有写入业务记录来冒充完整验收。

原始截图通过Codex内置浏览器的真实视口能力采集；没有以缩放图片或独立组件预览代替实际应用。其余浏览器、手机真机/软键盘、系统字体放大和长期使用未新增验收。原生折射的跨浏览器光学表现仍由各目标平台实际判断。
