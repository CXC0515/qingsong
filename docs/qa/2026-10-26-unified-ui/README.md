## 已观察

- 1280×720：教案、批改、诊断切换使用同一移动选中片；诊断不再包厚白底工具栏。移除旧淡入持久合成层后，选中片由灰恢复清透，E参数未改。
- 900×700：课堂页面宽度900，无页面水平溢出；普通班级组件约155.7px，顶部自然折行。
- 375×568：课堂任务宽度375、名单三列（约110px/列）；类别/记录页切换、班级/日期、项目与改名、搜索统计、操作、展开说明均可见。轮次进入操作行，不独占上下文空白行。
- 手机教案宽度375，无页面水平溢出；示例任务按紧凑卡片排列。截图拍摄后又隐藏了手机桌面列标题，类型检查和构建通过。
- 手机批改新建为共享底部弹窗，字段16px、班级选择独立；没有提交批改任务。桌面打开班级子弹窗、返回新建弹窗再取消的流程已检查。
- 桌面学生新建弹窗宽1024px，无自身水平溢出；没有保存学生或修改真实名册。

本次截图与布局抽查不代表全部流程或全部平台通过。手机真机、软键盘、Safari/Android、200%缩放、真实阅卷及长时间点名未验证，按用户约定由其使用验收。轮次实际写入、重试、隔离和恢复通过后端/HTTP专项验证，未在试用账号内新增点名记录。
