# 工作台三处界面修正

- 版本：v1.0
- 日期：2026-11-10
- 状态：实现完成，发布验证中
- 授权：用户要求“三个修一下，直接出了方案就开始修，修完部署”。

## 原始问题和目标

常用工作标题在电脑端挤到按钮左侧；工作台助手可缩得过窄；手机设置中的四个原生下拉框体验不一致。目标是修复这三个可见问题，保留工作台结构、2×2入口与原有保存逻辑。

## 事实、假设及方案

已确认标题偏位来自桌面横向 flex 覆盖；助手共享最小宽度为320px；入口配置使用原生 select。需要修改前端代码。采用最短路径：移除标题横排覆盖，使用12px标题；仅工作台桌面助手最小480px，并纠正旧窄宽度偏好；复用现有响应式选择弹层，点击位置后选择功能。

480px为本次界面决策，手机助手仍跟随可用视口。备选是继续原生下拉并增加样式，但无法统一手机浏览器的选项呈现，因此未采用。没有新的业务接口、数据库或AI工具权限变更，管理后台和AI备课实现不在范围内。

## 修改范围

- src/styles/product.css：标题、工作台助手轨道与最小宽度；轨道计入16px外边距，避免820px容器临界溢出。
- src/features/assistant/AssistantDock.tsx：工作台宽度下限、历史偏好、鼠标与键盘缩放边界；其他工作面仍为320px。
- src/features/settings/SystemSettingsPanel.tsx：四个位置按钮复用 ResponsiveChoiceDialog，保留已有互换、恢复默认、取消、保存。
