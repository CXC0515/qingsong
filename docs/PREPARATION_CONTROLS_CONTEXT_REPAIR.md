## 原始问题与证据

操作栏由多组flex-wrap叠加，手机保存/会话/资料工具占多行。普通打开助手、新会话、会话选择与原生侧栏重复。预设通过requestDraftInitialization的append策略反复累加。选区原来已携带版本、稳定段落id、文本，但没有可见引用及字符/表格定位。

生产陋室铭会话第二轮成功请求的输入含cache约33668 tokens，随后CONTEXT_WINDOW_EXCEEDED；登记窗口32768。上游原因是web profile禁用全局压缩组件，标准preset按Agent挂载，而青松preset的plugins为空，实际没有挂载压缩。另查到原生compaction-basic默认headroomTokens65536也超过窗口；只补挂载仍会预算失败。需同时挂载原生压缩组并配置真实预算，不扩大模型容量。原错误提示不区分溢出，仍建议原会话继续。

## 获批最短路径

标题/保存同排；宽屏所有教案操作同栏，实际剩余宽度不足时只保留版本、资料、任务、更多。低频操作进更多；删除重复页面会话操作，统一原生侧栏。备课信息替代本课要求。任务详细记录使用可关闭弹层。资料抽屉保留。

草稿初始化改keep，只空稿填短开头，不覆盖教师输入；选区通过正式composer input dock显示引用，可展开、移除，带版本、段落字符范围及表格起点行列。旧版本引用标失效，服务端不作为修改范围。正文由稳定id定位，不用视觉行号。

Harness显式设置窗口内压缩预算，复用原生历史摘要和受限/compact命令；错误提示提供整理历史，整理失败可新建同教案关联会话。保留旧历史，不自动重跑整轮、不改Skill或模型容量。
