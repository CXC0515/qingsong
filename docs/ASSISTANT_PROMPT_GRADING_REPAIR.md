# 助手提示词管理、批改解析与引用预览

版本：v1.0  
状态：实现完成，等待服务器构建与发布验收  
日期：2026-11-08

## 目标与范围

1. 修复 AI 批改解析可能得到空题目、同时仍允许空分析覆盖已有结果的风险；保留当前 GPT-6 系列模型配置。
2. 让管理员可查看和编辑实际进入 DSH 的青松教学规则及已发布 Skill，支持披露开关、版本对照、历史载入、保存回读和草稿保护。
3. 在 AI 助手输入区直接预览选中的教案文本及其版本和定位信息。

不修改 Skill 正文、模型身份、评分规则、OCR 供应商、教师数据或数据库结构。DSH 内部提示、工具定义与模型身份仍由运行时代码控制。

## 已确认事实

- 题目分析的严格 JSON Schema 和最终校验之前共用要求至少一题的 schema，空数组无法自然进入已存在的重试逻辑。
- 分析接口在解析结果全部校验完成后才执行持久化；分析失败会停留在原结果。服务端另有空结果保护。
- 当前助手规则由 `contextGuidance` 固定注入；仅添加管理员动态规则会造成两份规则同时进入上下文。
- Skill 文件已经由 Agent 子项目以 YAML frontmatter 发布；管理员配置保存于系统目录，运行中的轮次使用已装载快照。
- 当前模型配置读取已有 `visionModel`，本次没有改模型设置，也未发起真实供应商请求。

## 修改方案

- 将模型响应 schema 与最终接受 schema 分开：响应可以表达空数组以触发一次同模型重试；最终 schema 仍要求至少一题。第二次仍空时返回 `QUESTIONS_NOT_EXTRACTED`，不写入或清空旧分析及其关联审核数据。
- DSH 管理页只编辑线上实际使用的教学上下文和五个已发布 Skill。后台 API 限 owner，内容保存为原子版本文件并保留历史，使用 revision 防止并发覆盖；Skill 名称、描述和版本字段保持校验。
- 每轮 Agent 开始时读取管理员配置；删除并行的静态教学规则注入。Skill 列表和加载均受当前披露配置约束。
- 选区引用展开显示原文、教案版本和段落/表格定位。历史载入、重新载入和管理栏目离开均确认草稿处理。

## 验证

- 空结果重试到有效题目、两次空结果失败、题目分析 schema、批改试批、资料入库和视觉复核自动化测试。
- DSH Agent 工具与运行时回归、配置版本/冲突/Skill 元数据测试。
- 服务器指定 Node 24.22.1 下运行完整类型检查、构建和发布相关回归；检查生产资源哈希、服务健康和登录态桌面/窄屏 UI。
- 不进行真实模型调用。自动化不能代替正式教师账号的批改样本或真实手机体验验收。
