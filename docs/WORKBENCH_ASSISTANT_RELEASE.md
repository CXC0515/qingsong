## 实现范围

- 设置新增“工作台”：从侧栏功能选择四个入口，保持2×2；选择已占用功能交换位置。支持保存、取消、恢复默认，账号持久化与配置版本冲突保护。
- 今日课表、提醒日程仍上下排列。各自容器内容宽度达到600px、520px时切为两栏，窄屏单栏；字体及44px操作目标保留。
- Harness主Agent明确个人提醒授权规则；工具层新增qingsong_schedule，不改教案Skill或管理后台接口。明确事项直接创建；无时间先创建时间待定；部分时间保留原文约束。
- 依赖推测的创建只存提议，展示名称及时间，确认后才创建。补时间提议也必须确认；拒绝不删除原事项。服务端校验课表与已有日程，空档仅表示现有课表未排课。
- 相对日期以消息提交时刻、Asia/Shanghai解析。来源校验、账号/工作区/会话绑定、消息幂等、30分钟提议有效期、对象快照冲突检测及事务写入。
- 回复下方内联玻璃按钮，原生turnTail扩展，不替换教案或材料引用界面。矮屏将相关会话输入区改为自然滚动，避免遮挡确认。
- roster数据库17→21，仅新增快捷入口、日程操作与提议存储；原有业务表不重写。

## 边界与取舍

当前只开放个人单条创建、待确认创建及补/改时间；未开放批量、周期、硬删除、标记完成、课表修改或外部消息。自然语言时间解析保守；不支持的表达保留约束/提出确认，不猜精确时间。记录保存不代表到点推送通知已验证。未做物理手机、真实供应商模型或真实教师验收。

## 发布与回滚
