# 访客演示模式

- 版本：v1.1
- 状态：已部署，公网演示检查通过；真机与最终视觉体验待用户验收
- 日期：2026-11-02
- 本次概要：在现有应用增加可移除的纯前端演示，不创建真实账号、不接入真实数据库或模型。

## 问题、事实与决策

访客需要体验产品结构和主要操作。现有认证、业务 API、助手 iframe 均连接真实服务，仅公开共享教师账号不满足隔离目标。用户批准代码、方案文档和上线部署，要求保留已有功能并能干净撤除。

推荐最短路径：沿用现有页面，登录表单识别公开演示凭据并进入 `/?demo=1`；此文档中全部业务请求由浏览器内存模拟接口处理，未知请求明确拒绝，绝不回退真实 API。助手使用独立预设问答。备选独立演示后端成本更高，且多出数据存储，不采用。

展示数据全部合成；不能将示例回答、OCR 或分数当作实际模型能力验证。演示内的新增、编辑等只影响本标签页内存，刷新重置。现有教师登录和业务服务保持原状。演示凭据只是体验入口，不是安全凭据，不创建认证 cookie。

## 范围与风险

接入点为 `AuthGate.tsx`、`apiClient.ts`、`AssistantPanel.tsx`，另经用户追加批准在 `ResourceLibraryEditor.tsx` 和 `GradingWorkflow.tsx` 各替换一处图片来源；实现集中 `src/demo/`。不修改业务 schema、生产数据、模型配置、Nginx。复用页面可能新增请求，因此请求层严格拒绝未知请求，并在演示文档设置 `connect-src data: blob:; frame-src data: blob:; form-action 'none'; img-src <同源>/assets/ data: blob:`（只允许静态图片和浏览器本地内容） 作为第二道边界。样例文件只使用本地/内嵌资源，不引用真实上传路径。

浏览器个人设置使用专属模拟用户 ID；进入、重置、退出清理仅包含此 ID 的存储键，不清理真实账号偏好。用户主动上传在已模拟范围内仅在浏览器处理；未模拟操作清楚提示未保存。

## 验证与部署

运行类型、构建、模拟接口隔离/重置/CRUD 检查；在真实应用壳层检查电脑、平板、窄屏及低高度，记录控制台和网络请求。生产前确认当前版本、恢复点、活动任务及数据库完整性，候选检查通过后原子切换并验证健康、静态资源、匿名权限及公网演示。

## 关闭与干净撤除

- 临时关闭：构建时设置 `VITE_VISITOR_DEMO=false` 后发布，登录恢复原提示，`?demo=1` 不再进入演示；无需修改数据库。
- 完整撤除：移除上述五个接入点的 demo import/分支；删除 `src/demo/` 及本专项测试；重建发布。文档可按需要保留历史记录。
- 模拟账户没有服务端记录，数据无数据库、上传目录或定时任务可清理。
- 代码回滚使用上线前 release；不得恢复数据库来撤回演示功能。

### 公网预览补齐

线上既有CSP拦截 `data:` 文档 iframe（本地预览没有相同服务器响应头，未在初检覆盖）。在同一资料预览接入点为演示使用固定 `srcDoc` 原文，无网络请求，真实模式保持原 `src`。不放宽正式站安全策略、不改变教师原文流程。
