# 工作台、联系人与讲台旁座位

版本1.0 · 2026-10-27 · 状态：用户批准，本地实现与样本检查完成，待用户验收；未发布。

## 本次范围与取舍

原始问题：助手侧栏过宽、手机需下滑寻找助手、母系统Logo未替换、讲台缺旁座、学生只能记录一位联系人。用户批准在现有官方助手专项worktree实现，保留已有改动。

最短路径是复用官方侧栏状态、同一个助手iframe、既有座位与学生保存接口。没有建立第二套聊天或联系人数据库；不扩展批量导入、资料上传、RAG及业务写入。

- 助手会话侧栏默认180px；电脑拖动分界或方向键调宽，范围150～320px，拖动时为正文保留至少180px。宽度保留至组件卸载，刷新重置。官方rc.3原生拖动下限264px，因此用shell.overlay插槽提供局部手柄，继续复用官方开关状态；未改依赖源码。
- 手机工作台只显示右下AI助手入口，点击全屏打开，返回后原页面仍在；同一个iframe持续挂载，关闭再开保留会话和草稿。使用原生dialog提供模态与焦点约束。
- 母系统品牌复用用户定稿透明图形，新增src/assets/qingsong-logo.png。
- 讲台左右各两座，固定索引120～123，不改主座位0～119。可安排、换位、保存和导出；主座位行列轮换不移动讲台旁座，改变行列仍保留旁座。自动排列先主座位后旁座。
- 旧parent继续作为第一联系人，新增可选secondaryParent，两位均支持姓名、关系、电话、备注。第二位保存在现有profile_json；旧客户端未传第二位时保留，显式空字段可清空。
