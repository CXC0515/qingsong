# 工作台常驻与备课会话闭环

版本v1.1；2026-11-06；状态：已实现并验证，待生产发布。

目标：宽屏工作台常驻助手；列表不等待完整编辑器；进入教案自动切备课空间，一教案多会话且一会话唯一教案；503按阶段说明并核对保存结果。
事实：常驻只初次判断；上下文更新未导航助手；544KB教案入口静态引入编辑器；服务器近期列表2.7–4.1ms/详情2–7.8ms；00:12:11上海Luna调用503、535.56ms后重试仍503。供应商或网关根因未确认。
范围：App/AppLayout/AssistantDock、教案加载边界、绑定服务/API/原生助手界面错误展示及回归。复用DSH，不切换模型、不扩大材料权限、不自动应用候选。
路径：拆静态依赖、明确界面上下文、复用既有绑定和只读状态；拒绝跨教案绑定。放弃关闭编辑能力、盲删release、无限重试。
验证：宽窄切换/常驻/草稿、列表资源、教案A/B多会话隔离、新建幂等、503重试和结束核验、Linux同权限构建与测试、公网。风险：串会话、重复执行、保存状态误报。

## 实施结果

- 页面壳层：工作台宽度达到1100px时持续显示助手，移除收起入口及Escape收起；缩窄后恢复按需打开。保留已有工作台比例、手动宽度、同一个iframe及未发送草稿。
- 页面加载：备课列表与详情分包；历史及候选预览改为按需加载编辑器。列表入口由543,933字节降为7.94KB，详情32.43KB，编辑器506.43KB；这只是资源拆分数据，不是生产端到端延迟改善百分比。
- 业务会话：本教案会话选择与新建入口；服务端复用已有绑定表，一教案多会话，拒绝跨教案/教学版本绑定，打开会话更新最近使用时间；旧的session-UUID格式兼容。新建请求沿用同一个UUID重试；目录查询出错不再被当作已删除而创建重复会话。
- 助手界面：进入AI教案使用备课空间；打开具体教案定位最近会话，显式选择可打开旧会话。原生侧栏仍可浏览其他会话，但输入区显示该会话实际关联教案；未绑定会话不能调用备课写入工具。
- Harness外围反馈与只读核验：复用DSH keyed slots呈现重试/终止错误，提供中文原因；模型请求沿用既有一次重试，不自动重放整轮工具。错误后查询账号隔离的业务存储，显示当前版本、本会话待应用/已应用候选数和最近任务状态；无法读取时明确未知，不推断正文未修改或全部保存。核验按钮只读。主Agent、Skill路由、模型、额度与材料权限未改。
