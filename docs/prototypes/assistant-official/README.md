# 教学助手：官方 DSH UI 嵌入原型

- 版本：v0.2，2026-10-27。
- 状态：隔离原型，待用户确认方向；不是生产集成方案或部署授权。
- 本次概要：在青松实际工作台壳层中运行已安装的官方 DSH 0.2.1-rc.3 Web UI，验证直接复用的效果。
- 修改历史：v0.1 首次建立官方 UI 复用样本；v0.2 经用户批准，将空会话输入框置底，欢迎标题缩小变灰，副文案移除标签背景并进一步弱化。仅修改原型样式。

## 复用边界

官方负责消息渲染、Markdown/表格、流式输出、步骤折叠、Lexical 输入框、模型选择、消息操作与会话记录。没有另写一套聊天组件。

青松负责原有工作台和共享玻璃外壳、助手标题及历史/新对话入口。原型通过 Vite alias 替换助手入口，不修改生产源码。官方侧栏按需展开，编程工具入口暂时隐藏，输入文案与手机触控尺寸做局部适配。

`native-bridge.js` 通过官方 UI 控件转发操作并调整 DOM；`native-shell.css` 通过公开插槽标记周围的容器收敛布局。这是锁定版本的探索性适配，依赖当前 DOM，**不能直接作为生产接入方案**。正式接入需优先使用官方客户端插件、插槽和服务接口，并沿用青松登录与用户/工作区/会话隔离。

## 数据与运行

只使用临时目录中的样本账号、样本数据库和本机假模型 SSE 服务。`gpt-6-luna` 是原型选择器中的模型名，本原型没有调用真实模型或读取生产数据。样本回答固定为两节语文课；模型选择、工具调用、流式消息及历史记录由实际 DSH 运行时处理。

需要 Node 24.22.1，以及根目录和 `agent/` 已安装的依赖。在仓库根目录的两个终端分别执行：

```sh
node --import tsx docs/prototypes/assistant-official/serve.mts
```

```sh
node node_modules/vite/bin/vite.js --config docs/prototypes/assistant-official/vite.config.ts
```

打开 <http://localhost:4480/>。端口 4480 为青松原型，4481 为样本 API/反向代理，4482 为官方 DSH，4483 为假模型；均绑定回环地址。首次官方界面可能需确认预览提示、选择默认工作区和样本模型。停止时先结束 Vite，再向 `serve.mts` 进程发送 SIGTERM。

临时根目录记录在 `/tmp/qingsong-official-prototype-location`。如需继续已有样本会话，可将该路径作为 `QS_OFFICIAL_ROOT` 传给后端。请勿指向真实业务数据目录。本机代理中的自动登录、HTML 注入及启动令牌交换仅用于隔离预览。

## 文件

- `OfficialAssistantPanel.tsx`：青松外壳及 iframe。
- `vite.config.ts`：仅原型入口替换、样本自动登录与代理。
- `serve.mts`：隔离 API、官方运行时、假模型和本机代理。
- `tools.mjs`：样本工具与工具白名单。
- `native-shell.css`、`native-bridge.js`：原型主题和宿主适配。
