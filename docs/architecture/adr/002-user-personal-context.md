# ADR-002：个人规则与记忆归用户所有

日期：2026-10-27。状态：用户已确认，第一批实现；部署状态见PROJECT_HANDOFF。

用户明确要求一个人一份。个人规则与长期记忆使用 `system/assistant-users/<SHA256(userId)>/assistant-context.sqlite`，不以聊天或业务workspace创建副本。工作区规则仍归工作区，教学事实仍由业务服务按当前权限查询；本批不新增学校共享。

选择内置SQLite和DSH原生上下文快照，复用登录与在线产品备份；不新增外部memory服务或向量数据库，不修改定稿persona。模型提出候选，人工确认后生效；只有可由服务端与受信插件核对的当前人类原文命令可直接生效。HTTP变更使用操作编号和版本，删除保留墓碑，后续召回只取有效条目。

不采用按工作区复制个人库，避免同一用户不同聊天偏好分叉；也不依赖让模型任意编辑MEMORY.md维护权威数据。存储位置只是服务端实现，教师通过一个“规则与记忆”入口管理。

代价：需要维护少量结构化接口与来源/版本记录；删除个人记忆不等于擦除原对话、原生快照或备份，界面必须说明。跨组织数据携带不因用户库归属而自动授权，相关共享治理留待组织阶段。
